# Anime Vault

Anime Vault is a web application for discovering, browsing, and organizing anime titles.  
Built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**, it provides a modern, responsive, and fast experience optimized for deployment on **Vercel**.

---

## ✨ Features

-   🔍 **Search & Browse** — explore anime by title, genre, or popularity
-   📄 **Detail Pages** — view descriptions, genres, ratings, and artwork
-   📌 **Collections / Watchlist** — save anime to favorites or track your watch status
-   📱 **Responsive UI** — optimized for desktop and mobile
-   ⚡ **Fast Rendering** — SSR/SSG with incremental static regeneration
-   🚀 **Deploy-ready** — works out of the box with Vercel

---

## 🛠 Tech Stack

-   **Framework:** Next.js (App Router)
-   **Language:** TypeScript
-   **Styling:** Tailwind CSS / PostCSS
-   **Linting:** ESLint
-   **Fonts:** Geist via `next/font`
-   **Package Manager:** npm (compatible with yarn/pnpm/bun)
-   **Hosting:** Vercel

## 🚀 Getting Started

### Prerequisites

-   **Node.js** 18+
-   **npm** (or yarn/pnpm/bun)

### Installation

```bash
# Clone the repository
git clone https://github.com/jackal7819/anime-vault
cd anime-vault

# Install dependencies
npm install

# Run development server
npm run dev
```

## 📜 Scripts

•  npm run dev — start development server
•  npm run build — build for production
•  npm run start — run production build
•  npm run lint — run ESLint

## 📦 Deployment

### Vercel

1.  Import the repository into Vercel
2.  Configure environment variables in project settings
3.  Select Next.js as the framework
4.  Deploy
